## Security and correctness coverage

The selected set addresses:

- CVE-2026-68147, CVE-2026-68148, CVE-2026-72103, and CVE-2026-74595;
- post-EOF data exposure and original-data loss paths;
- F2FS UAFs in writeback, compression, inode, atomic-inode, and bio lifetime;
- dnode, device-path, sysfs, xattr, ACL, and shift/count bounds defects;
- checkpoint, extent, compressed-I/O, and GC lock/race defects;

  correctness defects; and

  selection safety.

## Static FBE/storage review

F2FS, fscrypt, blk-crypto, dm-default-key, UFS crypto, and Qualcomm ICE remain
built in or integrated exactly as qualified.  CVE-2026-68147 changes only the
allocation/lifetime mechanics of device enumeration.  F2FS returns the same
block devices, and native fscrypt uses them for the same key preparation and
eviction operations.  The new callback is stored in an existing Android KABI
reserve slot; the legacy callback slot and later member offsets remain intact.

No selected patch changes key formats, fscrypt policy formats, bio crypto
contexts, UFS/ICE programming, dm-default-key target semantics, or mount-time
configuration.  Static FBE/storage result: PASS.  Existing-user0 and TWRP PIN
decryption remain mandatory physical gates.

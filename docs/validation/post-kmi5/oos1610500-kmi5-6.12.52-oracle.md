# OnePlus 15 KMI5 Linux 6.12.52 source oracle

## Source identity

The post-KMI5 Linux LTS work starts from repository commit
`9af14ab9d3b280c6554b4d474e811f1bd8729e5b`.  Its common-kernel tree is
`33bef8cceea1d7df11b930a68c3a08fe3bde98eb`, byte-identical to the linear
source-equivalent commit `b3d0dbb64c77c39ae497b9a0b3a8362821cc9259`.

The physical 6.12.52 qualification produced by the same kernel source was:

- source-producing commit: `fa9fe14314c7b043f7d16f4b34397ff7d6eef68b`;
- identical full source tree: `53ebeb0e0a9e892d93e2d9d80aac4e0c4962bd05`;
- kernel: `6.12.52-android16-5-o-gfa9fe14314c7-4k`;
- boot SHA-256: `1aa1de79d79cfa5b184d2df4fb25fa56811f615d8420d5faf6c6dac29d49e41a`;
- KMI generation: 5.

That physical report is for OxygenOS 16.0.9.400, not 16.0.10.500.  It is
therefore source and boot-container evidence, but it is not falsely promoted
to a 16.0.10.500 physical qualification.  Before any post-KMI5 candidate is
flashed, device preflight must prove the requested 16.0.10.500 firmware and
exact supporting payload contract.

## OOS 16.0.10.500 stock-module oracle

The retained machine-readable module classification is
`docs/validation/firmware-16.0.10.500/ack-6.12.24-stock-module-compatibility.tsv`
(SHA-256 `62afa8f11cc49e42a92ae4211688d8e47f51a2eaf3fa55e440bd1d8b26266148`).
It contains 1,020 module rows: 984 active-compatible and 36 dormant.

The retained vendor-provider contract is
`docs/validation/ack-modernization/ack-6.12.24-vendor-kmi-contract.tsv`
(SHA-256 `9a6eb99973dcaf160a90369b0259c4b56d42842ac1b133e8ec7e93b792b5d300`).
The earlier extracted proprietary module trees were deliberately removed
during disk cleanup.  Until exact stock images are re-extracted, milestone
validation may replay these committed provider/import oracles but must not be
reported as a fresh binary scan.

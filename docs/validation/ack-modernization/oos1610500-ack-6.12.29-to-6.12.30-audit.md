## Scope and parent

This controlled update starts from repository commit
`a42551e7ea7d487ab0dffc53a8310b073477a080`, the published and physically
booted OxygenOS 16.0.10.500 ACK 6.12.29 state, and advances only the Android
Common portion from Linux 6.12.29 to Linux 6.12.30.

No Linux 6.12.31 or later stable commit is included. The update does not
change `system_dlkm`, `vendor_dlkm`, `vendor_boot`, DTBO, VBMeta, userdata,
metadata, the stock module load policy, or the pinned OnePlus and Qualcomm
source revisions.

## Android KABI repair

The stable interval includes `343a77562c1f` (`virtio_ring: add a func
argument 'recycle_done' to virtqueue_reset()`), which changes the exported
`virtqueue_reset()` API from two arguments to three. The plain 6.12.30 replay
therefore changed its CRC from the qualified stock-module contract and failed
the enforced ABI comparison.

Android Common supplied the authoritative generation-5 repair
`60eb68c4d8fcb305cc127c22dff1db46558b24a4`, explicitly reverting the API
change because it breaks Android KABI. It is retained as separate repository
commit `620f76c23662ce9239d2a7abe3073cb0f109cd08`. The semantic conflict in
`drivers/net/virtio_net.c` was resolved to the official Android 6.12.30
result: the surrounding XSK queue-reset fix remains, while the external
two-argument `virtqueue_reset()` contract is restored. No CRC, vermagic, or
DWARF type string was forged.

## Storage and FBE review

generated FBE/storage configuration is identical to 6.12.29, and the full
57,216-edge stock module import/CRC audit passes. Existing encrypted user0
remains the first physical-test oracle.

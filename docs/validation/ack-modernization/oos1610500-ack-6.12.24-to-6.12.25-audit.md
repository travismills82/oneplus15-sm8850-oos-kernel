## Reviewed Android integrations

### schedutil limits synchronization

Stable commits `00a1bdb15791` and `f73731983f28` were integrated while
preserving the existing Android `trace_android_rvh_set_sugov_update` hook.
The resulting implementation retains the upstream policy-limit,
`READ_ONCE`/`WRITE_ONCE`, and barrier behavior without dropping the vendor
hook contract.

### bus IRQ-affinity callback

Stable commits `5ec903970245` and `fe2bdefe8644` add a `bus_type` callback and
the generic block queue mapper. Appending the callback directly changed the
frozen `struct bus_type` layout and cascaded through module CRCs. The reviewed
integration leaves `ANDROID_KABI_RESERVE(1)` intact and uses a typed internal
accessor over that pointer-sized storage. Linux 6.12.25 has no bus provider
assignment for this callback, so its observable fallback behavior is retained
without exposing a changed structure to stock modules.

### BPF packet-data tracking

Stable commits `1d572c60488b` and `3846e2bea565` add
`changes_pkt_data` state to `bpf_subprog_info` and `bpf_prog_aux`. Direct field
insertion changed both structures and expanded `bpf_verifier_env`. The
reviewed integration stores the boolean state in each structure's existing
`ANDROID_KABI_RESERVE(1)` through internal accessors. All official read,
write, propagation, JIT, and attach-target checks remain present while the
frozen structure descriptions, sizes, offsets, and CRCs remain unchanged.

## Fail-closed KMI evidence

The first direct import intentionally failed the gates:

- 5,884 exported-symbol CRCs changed from qualified 6.12.24;
- 940 active stock modules were blockers;
- 20,347 stock import edges had CRC mismatches;
- the ABI report identified `bus_type`, `bpf_prog_aux`,
  `bpf_subprog_info`, and the resulting verifier/bindings propagation.

Using `ANDROID_KABI_USE` restored the CRCs but still produced five ABI-report
entries showing consumed reserves, so that intermediate result was also
rejected. The final raw-reserve accessor form produces five zero-byte ABI
reports and a `Module.symvers` byte-identical to qualified 6.12.24:

`6889e56eb427705a9002c7b030b2af7b9a6153c874efb1cda5ddaf56be60aa27`

The final stock-module audit passes all 57,216 import/CRC edges with zero
unresolved, CRC, protected-export, signature/trust, or structural-provider
failures.

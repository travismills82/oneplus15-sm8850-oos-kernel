## Reconciliation decisions

Three imported commits needed local reconciliation:

1. The Exynosauto ABI commit expected Google's full generated symbol list,
   while this repository intentionally carries a compact list.  The resolution
   retained the compact list and added exactly the six intended PCI symbols:
   `pci_epc_mem_alloc_addr`, `pci_epc_mem_free_addr`, `pci_epc_set_bar`,
   `pci_epc_unmap_addr`, `pci_num_vf`, and `pci_ioremap_wc_bar`.  Its official
   ABI additions were retained.
2. Proxy-exec v19 overlapped the later stable `trace_sched_switch()`
   `prev_state` fix and Oplus WALT consumers.  The resolution keeps
   `unsigned long *task_state_p`, assigns `TASK_RUNNING` through that pointer,
   and adopts v19 `should_block` behavior without restoring obsolete scheduler
   behavior.  The final WALT and scheduler modules compile.
3. The Gunyah ABI commit overlapped functionality and an ABI record already
   carried by the imported OnePlus base, plus existing F2FS tracepoint
   allowances.  The resolution retained the already equivalent functional
   code and the Gunyah/F2FS allowances; the provenance commit has no runtime
   delta and only normalizes the trailing end of that allowance file.

The pinmux race repair and `perf_try_init_event()` cleanup were already fully
present, so duplicate patches were dropped rather than creating empty or
misleading commits.

## Functional and storage review

The 6.12.38 delta changes scheduler/proxy-exec behavior, hung-task diagnostics,
Gunyah status representation, symbol lists, an x86-only TSA check, and the
kernel sublevel.  It does not change common F2FS, fscrypt, blk-crypto,
device-mapper, SCSI/UFS, Qualcomm ICE, or Canoe storage source.  Existing
encrypted user0 remains a mandatory physical oracle; this audit does not call
the untested candidate physically qualified.

No source configuration was changed by this interval.  The generated Canoe
configuration retains built-in CIFS and its dependencies:

```text
CONFIG_CIFS=y
CONFIG_NETFS_SUPPORT=y
CONFIG_NLS_UTF8=y
```

It also retains `CONFIG_WQ_POWER_EFFICIENT_DEFAULT=y`,
`CONFIG_MQ_IOSCHED_ADIOS=y`, SHA-512 module signing, MODVERSIONS,
GENDWARFKSYMS, F2FS, fscrypt, inline encryption, dm-default-key, and UFS.

## Compatibility policy

No stock supporting partition is modified.  The candidate contract remains
boot-only with exact OxygenOS 16.0.10.500 stock `system_dlkm`, `vendor_dlkm`,
`vendor_boot`, DTBO, and VBMeta.  No ABI reference was locally refreshed, no
symbol CRC was patched, and no signature, protected-export, ABI, or KMI gate
was weakened.

Build, ABI, signing, provider, and boot-container results are recorded in
`oos1610500-ack-6.12.38-static-validation.md`.

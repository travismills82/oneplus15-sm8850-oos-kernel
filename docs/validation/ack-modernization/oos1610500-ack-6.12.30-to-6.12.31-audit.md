# OOS 16.0.10.500 ACK 6.12.30 to 6.12.31 audit

## Scope and parent

This controlled update starts from repository commit
`ba43d41251812df0f07d13189174e3174e2b46d8`, the physically booted
OxygenOS 16.0.10.500 ACK 6.12.30 state with ADIOS and power-efficient
workqueues enabled, and advances only the Android Common Kernel stable state
from Linux 6.12.30 to Linux 6.12.31.

The experiment branch is
`experiment/oos1610500-ack-6.12.31-from-6.12.30`. No Linux 6.12.32 or later
stable commit is included. The update does not change the stock
`system_dlkm`, `vendor_dlkm`, `vendor_boot`, DTBO, VBMeta, userdata, metadata,
module load policy, or pinned Qualcomm and OnePlus source revisions.

## Semantic conflict resolutions

Conflicts were resolved by retaining both the stable fix and the downstream
device behavior:

- UFS PA_HIBER8TIME: the generic core quirk is retained. The duplicate Qualcomm
  implementation is removed, and the core recognizes the stock OOS legacy
  bit-15 contract so the same 100 microsecond adjustment is not applied twice.
- UVC sanity and menu translation: the stable validation/refactor intent is
  retained without discarding the already-integrated local equivalent.
- Scheduler base slice: the new 700 microsecond upstream default is retained
  while preserving the exported Oplus control variable.
- F2FS sysfs base attributes: the upstream organization is combined with the
  local linear-lookup behavior rather than replacing either side wholesale.
- Page allocation cpuset retry: the upstream bounded-retry fix remains while
  the Oplus accounting path is preserved.

No unresolved conflict marker remains.

## OOS compatibility adaptations

Eight downstream commits remain distinct from the official stable ancestry:

1. retain the legacy blocking `mctrl_gpio_disable_ms()` export as a wrapper
   while keeping the new synchronized and non-blocking interfaces;
2. reconcile the generic UFS PA_HIBER8TIME quirk with the OOS Qualcomm quirk;
3. preserve the generation-5 ahash module-visible type contract;
4. preserve the generation-5 `msi_desc` type contract;
5. preserve the generation-5 xHCI host-controller type contract;
6. preserve the generation-5 `inet6_cork` type contract;
7. avoid making dma-buf internals visible through exported DRM types after the
   final helper no longer needs the full header;
8. keep the page-pool NAPI race assertion while avoiding private netdev type
   visibility through exported page-pool APIs.

The first compatibility pass still had 89 CRC-only symbol changes and seven
active stock-module blockers. The DRM and page-pool visibility repairs remove
the final transitive type exposure. The final `Module.symvers` is byte-for-byte
identical to the qualified 6.12.30 state.

## Storage and FBE review

The stable interval's block, SCSI, UFS, runtime-PM, crypto, device-mapper,
F2FS, and memory changes were reviewed as part of the static gate. The
effective Canoe configuration does not change, the enforced common ABI is
empty, and all 57,216 imports from the stock module universe resolve with
matching CRCs. The UFS quirk reconciliation prevents duplicate programming of
PA_HIBER8TIME.

This is static evidence only. Existing encrypted user0 and absence of
`init_user0_failed` remain the first physical boot oracle.

# OOS 16.0.10.500 ACK 6.12.31 to 6.12.32 audit

## Scope and parent

This controlled update starts from repository commit
`4e1fed10b7e823970e4673f6da226d52b8bbc0dc`, the physically qualified
OxygenOS 16.0.10.500 ACK 6.12.31 state, and advances only the Android Common
Kernel stable state from Linux 6.12.31 to Linux 6.12.32.

The experiment branch is
`experiment/oos1610500-ack-6.12.32-from-6.12.31`. No Linux 6.12.33 or later
stable commit is included. The update does not change the stock
`system_dlkm`, `vendor_dlkm`, `vendor_boot`, DTBO, VBMeta, userdata, metadata,
module load policy, or pinned Qualcomm and OnePlus source revisions.

## Android KABI repair

Linux stable commit `b5325b2a270f` adds a pidfd to the usermode coredump
helper and changes module-visible coredump types. Android Common later applies
`b914826a458755697d0b1945a87f6a21931d9495`, explicitly reverting that change
because it breaks Android KABI. The repair is retained separately after the
complete 6.12.32 replay. It does not undo the preceding coredump
`replace_fd()` error-handling fix.

After the repair, the net source delta has no coredump header change. The only
header changed from 6.12.31 is NFS-internal, and NFS is disabled in the Canoe
configuration.

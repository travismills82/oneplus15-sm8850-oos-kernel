- `tools/bazel build --kbuild_symtypes //common:kernel_aarch64`;
- `tools/bazel run //common:kernel_aarch64_abi_dist -- --destdir=out/abi-release-6.12.52`;

- the complete Canoe distribution build used to produce the tested Image;

The common ABI comparison completed with an empty difference. Strict KMI and
symtypes passed. The Canoe ABI target generated the device-module-inclusive
ABI dump; as documented by this repository, that target is not itself an
enforced device ABI diff.

The retained `.400` stock-module audit checked 1,018 modules:

failures, signature failures, or structural-provider blockers. Rust Binder's

The final generated configuration retains built-in CIFS/NetFS/UTF-8 NLS,

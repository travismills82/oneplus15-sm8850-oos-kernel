# OOS 16.0.10.500 ACK 6.12.35 to 6.12.36 audit

## Scope and parent

This controlled boot-only experiment starts from repository `main` commit
`f8e7754f6c5b25cf2d268b584b2d8f3f8ff1724d`, whose runtime source
`96fce14273ea4f73ccd453bf4ba3cb31c6e24ec9` passed the ENC-S02/ENC-S03
TWRP metadata/PIN decryption and Android existing-user0 FBE canary.  The
experiment advances only the Android Common/Linux stable point release from
6.12.35 to complete 6.12.36.

The branch is `experiment/oos1610500-ack-6.12.36-no-bad-dm`.  It does not
contain Linux 6.12.37 or later work.  It does not change `system_dlkm`,
`vendor_dlkm`, `vendor_boot`, DTBO, VBMeta, userdata, metadata, the stock
module-loading policy, or the pinned Qualcomm/OnePlus source projects.

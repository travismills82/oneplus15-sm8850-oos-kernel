## Downstream compatibility adaptations

The upstream interval required narrow Android/OOS KMI adaptations. The newer
stable behavior is retained while the ColorOS 17.0.0.102 external contract is
preserved for:

- the netdevice namespace helper, watchdog state, and `netns_local` storage;
- GPIO setter callback return types;
- additive skb drop reasons;
- smart-suspend state stored in the existing `dev_pm_info` KABI reserve;
- cfg80211 disconnect work conversion;
- WireGuard/per-net RTNL teardown ordering;
- netfilter RCU state;
- I3C deferred device registration without growing the public device object;
- V4L2 mem2mem lifetime tracking in a private wrapper;
- blk-cgroup, folio-queue, and BPF verifier internal state;
- Bluetooth `hci_conn` protocol locking; and
- the internal XSK pool representation, whose qualified type view is retained
  without altering the upstream runtime layout.

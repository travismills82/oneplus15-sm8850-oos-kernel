# ColorOS/OxygenOS 17.0.0.102 kernel compatibility report

Date: 2026-10-25

## Scope

This record covers the physically qualified tree developed on
`experiment/oos1700102-kmi6-compat`, based on the OxygenOS 16 `main` commit
`3b4aea7fd69140c5ab5a9ffabc01433d8785340f`. The qualified source changes are
recorded through `041fc63003508b49fd9f101e1e130c9ec96854ab`. The release retains
Linux 6.12.112, Android 16 ACK, and KMI generation 6. It is boot-only for the
OnePlus 15 CPH2745IN running firmware 17.0.0.102(EX01).

The production payload contract is:

```text
qualified boot.img
+ stock OxygenOS 17.0.0.102 system_dlkm
+ stock OxygenOS 17.0.0.102 vendor_dlkm
+ stock OxygenOS 17.0.0.102 vendor_boot
+ stock OxygenOS 17.0.0.102 dtbo/vbmeta/init_boot
```

No supporting partition was changed or repackaged for this release.

## Compatibility changes

Eleven source/build files differ from the base commit:

1. `kernel_platform/common/rust/Makefile`
   - Removes the OxygenOS 16.0.10.601-only suppression of AutoFDO for
     `core.o`.  Stock OxygenOS 17 builds Rust core normally with AutoFDO.
2. `kernel_platform/common/rust/bindgen_parameters`
3. `kernel_platform/common/rust/bindings/lib.rs`
4. `kernel_platform/common/rust/uapi/lib.rs`
5. `kernel_platform/common/rust/helpers/net/genetlink.c`
   - Remove the OxygenOS 16.0.10.601 opaque `struct net` adaptation and its
     type-string override.  OxygenOS 17's stock Rust Binder contract uses the
     generated current net bindings.
6. `kernel_platform/common/rust/helpers/poll.c`
   - Remove OxygenOS 16.0.10.601-specific `PollCondVar` type-string rules.
     OxygenOS 17 naturally produces the shipping symbol versions without
     them.
7. `kernel_platform/common/rust/kernel/page.rs`
   - Restore the `#[inline]` annotations present in the exact OxygenOS 17
     stock common source for `Page::alloc_page` and `Page::drop`.
8. `kernel_platform/common/drivers/memory/tegra/mc.c`
   - Adds narrow GENDWARFKSYMS type strings for the shipping opaque Tegra
     memory-controller type graph.  `arm_smmu.ko` stores only an opaque
     `struct tegra_mc *` and uses the exported accessors; it does not
     dereference the private Tegra layout.  Runtime structures and the newer
     6.12.112 implementation are unchanged.
9. `kernel_platform/soc-repo/kleaf-scripts/android_build.bzl`
   - Replaces the old OxygenOS 16 boot AVB fingerprint/security patch with the
     exact stock OxygenOS 17.0.0.102 boot properties.
10. `kernel_platform/common/arch/arm64/configs/gki_defconfig`
    - Selects the exact OxygenOS 17 stock GKI module-signing trust anchor.
11. `kernel_platform/common/certs/oos17_0_0_102_stock_gki_module_signing.pem`
    - Adds only the public certificate extracted from and verified against the
      stock 17.0.0.102 Image and protected modules.

No symbol CRC was edited, forced, or copied into Module.symvers.  The repaired
CRCs arise from normal Rust/Clang/GENDWARFKSYMS compilation.

## Qualification status

Static boot-only compatibility: **PASS**, subject to the explicitly blocked
enforced-common-ABI target described above. The production Canoe distribution,
strict KMI actions, Canoe ABI generation, boot-container checks, and complete
stock-module oracle passed.

Physical device qualification: **PASS WITH DOCUMENTED STOCK-MODULE
WARNINGS**. The exact `boot.img` passed full active-slot read-back, Android/FBE,
stock Rust Binder and module loading, Wi-Fi, Bluetooth service, LTE/RMNET,
camera capture, video plus microphone recording, media playback, fingerprint
unlock, NFC service toggle, USB/charging, display, ZRAM, CPUFreq, and fatal-log
scans. The device remained on the candidate.

The Oplus HBP fortify warning, schedinfo slab-constructor warning, and repeated
`clk_qcom` tracepoint-registration warning are rooted in unchanged stock vendor
modules and are not hidden. An external NFC tag, an actual Bluetooth peripheral
session, USB-disconnected deep suspend, TWRP decryption, and repeated cold/warm
boots were not exercised in this release session. See the separate physical
qualification record for exact evidence.

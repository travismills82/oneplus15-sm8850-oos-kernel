## Installer write scope

Static inspection and the repository validator prove that the only flash
target is `BOOT_BLOCK`, resolved at runtime as the active-slot
`boot_a` or `boot_b` block device. The other `dd` output is the durable backup
file. The rollback path writes that backup only to the same boot block.

The installer reads the active stock `system_dlkm` mapper solely to verify its
EROFS magic and exact 14,131,200-byte payload SHA-256:

```text

```

It contains no command that writes, maps, unmaps, resizes, erases, or flashes
`system_dlkm`, `system_dlkm_oki`, `vendor_dlkm`, `vendor_boot`, DTBO, or any
VBMeta partition. It does not change slot metadata or disable AVB.
